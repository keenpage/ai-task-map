# KeenPage AI Task Map by Occupation

How much of the everyday work in 2,000 occupations can AI help with? This dataset summarizes 25,000 work tasks across 38 industries, one row per occupation.

- Report: https://keenpage.com/en/ai-task-map
- Chinese report: https://keenpage.com/zh/ai-task-map
- Version: 2026-11-06

## Read this before using it

These figures are **model-assisted estimates, not survey or measurement results**. The lists include only work AI can help with, so a percentage does not say how much of a job AI can replace. See `METHODOLOGY.md`.
